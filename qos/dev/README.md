# qos/dev — QoS suite design notes

Internal design documents for the QoS mod suite. The mods
themselves are the sibling folders; the shipped suite readme is
[../SUITE-README.txt](../SUITE-README.txt).

- [ARCHITECTURE.md](ARCHITECTURE.md) — the suite's shared
  architecture pattern (one shape across all mods).
- [BUILD-NOTES.md](BUILD-NOTES.md) — build/staging notes for the
  net48 toolchain.
- [DESIGNATION-DESIGN-NOTE.md](DESIGNATION-DESIGN-NOTE.md) — the
  designation job family design (QoSBuilder 0.2.0).
- [PATTERN-SURVEY.md](PATTERN-SURVEY.md) — the survey of patterns
  across the suite's services.
