# dev/ — the development paper trail

How Superintendent and its mods were designed and built. Historical
documents are **not rewritten** — corrections and later rounds land
as addenda inside the same files, so the trail shows what was
believed when.

- [SPEC.md](SPEC.md) — the build specification, addendum by
  addendum (the current state of the contract).
- [DESIGN.md](DESIGN.md) — the design system: v2 invariants and the
  Design V3 addendum (page contracts, the Guidance domain, the
  canon, the rename, this restructure).
- [DESIGN-V3-BRIEF.md](DESIGN-V3-BRIEF.md) /
  [DESIGN-V3-AUDIT.md](DESIGN-V3-AUDIT.md) — the V3 brief (the
  owner's six principles) and the per-page audit that specified
  the round.
- [NIGHT-LOG.md](NIGHT-LOG.md) — the session-by-session build log.
- [QUALITY-AUDIT.md](QUALITY-AUDIT.md) — the style / effectiveness /
  test-equivalence audit and its fixes.
- [MOD-SURVEY.md](MOD-SURVEY.md), [QOL-MODS.md](QOL-MODS.md),
  [QOL-MOD-PREP.md](QOL-MOD-PREP.md) — the mod landscape survey and
  the QoS suite's preparation notes.
- [RELEASE-NOTES-DRAFT.md](RELEASE-NOTES-DRAFT.md) /
  [RELEASE-RUNBOOK.md](RELEASE-RUNBOOK.md) /
  [RELEASE-WORKFLOW-DRAFT.md](RELEASE-WORKFLOW-DRAFT.md) — release
  working documents (the workflow draft is pasted into GitHub's web
  UI by the repo owner; it is not a live workflow file).
- [api-routes-0.8.8.json](api-routes-0.8.8.json) — the captured
  web-API route inventory for game v0.8.8.
- [design-mock/](design-mock/) — design mock-ups and the measured
  screenshot sets (v2 `shot2-*`, v3 `shot3-*`).
- [captures/](captures/) — synthetic test fixtures: full stub-server
  captures the check scripts and page measurements run against
  (`live-synthetic-v065`, and the `live-synthetic-fixnow` variant
  that produces a genuine Fix-now issue for the badge test).
