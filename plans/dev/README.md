# plans/dev — plan working papers

Dry-run reports, timelines and status notes for the plans in
[../](../) (the YAML plans and their generated JSON stay at the
plans/ top level — they are the runtime inputs).

- `*.dryrun.md` — engine dry-run reports; the two Python reference
  reports (fresh-start-v1, dragon-isle-continuation-v1) are the
  inputs `tools/check_plan_parity.py` holds the Rust engine to.
- [verdicts.json](verdicts.json) — generated by
  `tools/gen_verdicts.py` (historical: once embedded by the
  website; the Plans page no longer ships run verdicts).
- [WEEKEND-RUNBOOK.md](WEEKEND-RUNBOOK.md),
  [continuation-history-states.md](continuation-history-states.md),
  [growth-sequence-timeline.md](growth-sequence-timeline.md),
  [growth-sequence-timeline-v2.md](growth-sequence-timeline-v2.md),
  [plans-blueprint-status.md](plans-blueprint-status.md) — working
  notes from the plan-authoring rounds.
