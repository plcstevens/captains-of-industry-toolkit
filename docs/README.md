# docs/ — player-facing documentation

Deeper documentation for players, beyond the root trio
([README](../README.md), [INSTALL](../INSTALL.md),
[REMOTE-ACCESS](../REMOTE-ACCESS.md)).

- [guides-research.md](guides-research.md) — the research digest
  behind the in-app *Learn the game* guides: sources, verdicts, and
  the reasoning the guides compress.
- [guides-earthworks.md](guides-earthworks.md) — earthworks in
  depth: dumping, flattening, mining designations, settling, and
  the purity ladder behind the /designate page.
- [GAME-PLAN-FORMAT.md](GAME-PLAN-FORMAT.md) — the game-plan file
  format: how a plan's phases, gates and orders are written, for
  players reading or authoring plans (the plans themselves live in
  [../plans/](../plans/)).
- [canon/](canon/) — **the canon**: the single source of every
  number and rule the tool's reasoning depends on, with its
  provenance. The website's *Why it suggests* pages render from it;
  [canon/README.md](canon/README.md) defines the entry shape and
  the status vocabulary.

Agent-facing material is indexed from [../.llms/](../.llms/llms.txt);
the development paper trail lives in [../dev/](../dev/).
