# bridge/recon — API surface recon tool

A throwaway-console recon program used to interrogate the game's
assemblies (via reflection / ilspy output) when a new bridge route
needs a verified manager surface before it is written into
CoiBridge proper. Not shipped; run locally against a game install.
See [../dev/MODDING-NOTES.md](../dev/MODDING-NOTES.md) for the
workflow it supports.
